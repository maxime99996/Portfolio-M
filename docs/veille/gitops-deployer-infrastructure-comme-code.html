GitOps : déployer son infrastructure comme on gère son code

Publié le 05/12/2025 | Tags : GitOps DevOps ArgoCD Kubernetes

Le GitOps est une approche DevOps née d'une idée simple : si on versionne le code applicatif dans Git, pourquoi ne pas faire pareil avec l'infrastructure ? En GitOps, l'état souhaité de tout le système — déploiements, configurations, règles réseau — est décrit dans un dépôt Git. Ce dépôt devient la source de vérité unique, et tout changement passe obligatoirement par une pull request.

Schéma — Le workflow GitOps avec ArgoCD

1
Développeur ouvre une Pull Request Git

Modification d'un fichier YAML de déploiement Kubernetes (image, replicas, variables d'env…) sur la branche main.

2
Revue de code & merge CI/CD

La pull request est relue, les tests automatisés s'exécutent (GitHub Actions / GitLab CI). Après validation, le merge est effectué.

3
ArgoCD détecte la divergence ArgoCD

L'agent ArgoCD surveille en continu le dépôt Git. Il détecte que l'état du cluster ne correspond plus à l'état décrit dans Git.

4
Réconciliation automatique Kubernetes

ArgoCD applique automatiquement les changements sur le cluster. Si quelqu'un modifie manuellement le cluster, ArgoCD écrase pour revenir à l'état Git.

Comparatif — Déploiement classique vs GitOps

❌ Avant — Déploiement manuel
  • Connexion SSH directe au serveur
  • Commandes kubectl apply manuelles
  • Aucune traçabilité des changements
  • Rollback difficile et risqué
  • Configurations divergent entre envs
✅ Après — GitOps
  • Tout passe par une pull request
  • Chaque changement = un commit traçable
  • Rollback = git revert en 30 secondes
  • Accès SSH au serveur supprimé
  • Environnements toujours synchronisés

💡 À retenir pour un projet SLAM
En BTS SIO, on utilise déjà Git au quotidien pour versionner son code. Le GitOps applique exactement les mêmes réflexes à l'infrastructure. Maîtriser GitHub Actions pour automatiser les déploiements est un premier pas très accessible vers cette pratique, sans avoir besoin d'un cluster Kubernetes complet.
